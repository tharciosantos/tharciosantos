### HelpFlow — Sistema de help desk full stack

Sistema completo para gerenciamento de chamados com:

- Autenticação NextAuth com controle de acesso por papéis (CLIENT/AGENT)
- CRUD de tickets com validação Zod
- Rate limiter em memória e senhas com hash via bcryptjs
- Testes com Vitest e Cypress E2E

### ManutFlow — Sistema de Controle de Manutenção

Sistema completo para cadastro de equipamentos, abertura de ordens de serviço e dashboard com indicadores em tempo real:

- Autenticação com Supabase Auth (3 camadas de segurança)
- Isolamento de dados por usuário (RLS + user_id)
- Breadcrumbs, auto-refresh do dashboard e loading skeletons
- CRUD completo com histórico de alterações
