## 📦 Projetos em destaque

### [HelpFlow](https://github.com/tharciosantos/helpflow) — Sistema de help desk `Publicado`

Aplicação full stack para gerenciamento de chamados, na qual implementei autenticação, autorização por usuário, CRUD de tickets, validação de dados e testes automatizados.

- **Principal desafio:** garantir que cada usuário acesse e gerencie somente os próprios chamados.
- **Qualidade:** validação de dados e testes automatizados com Vitest e Cypress.

`Next.js` · `JavaScript` · `Prisma` · `Supabase` · `PostgreSQL` · `Vitest` · `Cypress`

[Aplicação](https://helpflow.vercel.app/login) · [Código-fonte](https://github.com/tharciosantos/helpflow)

### [ManutFlow](https://github.com/tharciosantos/manutflow) — Controle de manutenção `Publicado`

Sistema no qual implementei o cadastro de equipamentos, o gerenciamento de ordens de serviço, um dashboard com indicadores e o histórico de alterações.

- **Principal desafio:** proteger e isolar os dados de cada usuário com autenticação e RLS.
- **Experiência de uso:** breadcrumbs, atualização automática e estados de carregamento.

`Next.js` · `TypeScript` · `Tailwind CSS` · `Supabase` · `PostgreSQL`

[Aplicação](https://manutflow.vercel.app) · [Código-fonte](https://github.com/tharciosantos/manutflow)

### [DevLinks](https://github.com/tharciosantos/devlinks-web) — Plataforma de links personalizados `Publicado`

Projeto com frontend e API separados, no qual implementei autenticação JWT, upload de imagens e sincronização de estado assíncrono.

- **Principal desafio:** integrar frontend, API, banco de dados e armazenamento de imagens.
- **Qualidade:** testes E2E com Cypress executados pelo GitHub Actions.

`React` · `Vite` · `Express` · `MongoDB` · `TanStack Query` · `Cloudinary` · `Cypress`

[Aplicação](https://devlinks-web-api.vercel.app/) · [Frontend](https://github.com/tharciosantos/devlinks-web) · [API](https://github.com/tharciosantos/devlinks-api)

> Outros projetos: [Crypto Dashboard](https://crypto-dashboard-five-sandy.vercel.app/) e [Lista de Mercado PWA](https://lista-mercado-sage.vercel.app/).
