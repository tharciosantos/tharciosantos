## Projetos em destaque

### [HelpFlow](https://github.com/tharciosantos/helpflow) — Sistema de help desk

Aplicação Full Stack para gerenciamento de chamados internos, com autenticação por credenciais e GitHub, recuperação de senha e controle de acesso por perfil e propriedade dos chamados.

- **Destaques:** CRUD paginado de tickets, validação com Zod, rate limiting e testes unitários e E2E.
- **Principal desafio:** garantir que cada usuário acesse e gerencie somente os chamados permitidos.

`Next.js` · `JavaScript` · `Prisma` · `Supabase` · `PostgreSQL` · `NextAuth` · `Vitest` · `Cypress`

[Aplicação](https://helpflow.vercel.app/login) · [Código-fonte](https://github.com/tharciosantos/helpflow)

### [ManutFlow](https://github.com/tharciosantos/manutflow) — Sistema de manutenção

Sistema para controle de equipamentos, ordens de serviço, prioridades, responsáveis e histórico de alterações.

- **Destaques:** 153 testes automatizados em 13 arquivos, CRUD com busca, filtros, paginação e dashboard operacional.
- **Segurança:** autenticação com Supabase e isolamento de dados em camadas com `proxy.ts`, `getUser()` e RLS.

`Next.js` · `TypeScript` · `Tailwind CSS` · `Supabase` · `PostgreSQL`

[Aplicação](https://manutflow.vercel.app) · [Código-fonte](https://github.com/tharciosantos/manutflow)

### [DevLinks](https://github.com/tharciosantos/devlinks-web) — Plataforma de links personalizados

Projeto com frontend e API separados, com autenticação JWT, upload de imagens, sincronização de estado assíncrono e testes E2E no GitHub Actions.

`React` · `Vite` · `Express` · `MongoDB` · `TanStack Query` · `Cloudinary` · `Cypress`

[Aplicação](https://devlinks-web-api.vercel.app/) · [Frontend](https://github.com/tharciosantos/devlinks-web) · [API](https://github.com/tharciosantos/devlinks-api)

Outros projetos: [Crypto Dashboard](https://crypto-dashboard-five-sandy.vercel.app/) e [Lista de Mercado PWA](https://lista-mercado-sage.vercel.app/).
